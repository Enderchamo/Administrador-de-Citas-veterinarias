# 🐾 CitasPet — Administrador de Pacientes Veterinarios

Aplicación web para gestionar citas y llevar un seguimiento de pacientes veterinarios, desarrollada con **React, TypeScript y Tailwind CSS**.

Este proyecto es una migración de una aplicación originalmente creada con HTML, CSS y JavaScript vanilla, con el objetivo de aprender React, mejorar la organización del código y aplicar buenas prácticas de desarrollo frontend.

## 🚀 Tecnologías utilizadas

- **React:** construcción de interfaces mediante componentes.
- **TypeScript:** tipado estático para mejorar la seguridad y el mantenimiento del código.
- **Vite:** entorno de desarrollo y compilación.
- **Tailwind CSS 3:** diseño y estilos de la interfaz.

## ✨ Funcionalidades

### Implementadas

- Formulario para introducir información de pacientes veterinarios.
- Manejo de inputs controlados mediante React.
- Hook personalizado `useFormulario` para administrar el estado del formulario.
- Actualización dinámica de campos con una función `handleChange`.
- Limpieza del formulario mediante `limpiarFormulario`.
- Captura de datos mediante el evento `onSubmit`.

### En desarrollo

- Registro y visualización de citas.
- Edición de citas existentes.
- Eliminación de citas.
- Validación de los campos del formulario.
- Gestión de citas mediante el hook personalizado `useCitas`.

## ⚙️ Instalación y ejecución

**1. Instalar las dependencias**

```bash
npm install
```

**2. Iniciar el servidor de desarrollo**

```bash
npm run dev
```

## 🎯 Objetivos de aprendizaje

Este proyecto busca reforzar conocimientos sobre:

- Componentes y props en React.
- Hooks como `useState`.
- Creación de hooks personalizados.
- Comunicación entre componentes.
- Manejo de eventos y formularios controlados.
- Tipos e interfaces en TypeScript.
- Actualización inmutable de objetos y arreglos.
- Separación de responsabilidades y organización del código.
